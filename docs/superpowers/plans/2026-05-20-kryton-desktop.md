# Kryton Desktop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a cross-platform desktop client (`kryton-desktop`) that wraps the existing Kryton web UI in a Tauri 2 shell with multi-account support and native OS integrations (tray, global shortcuts, native menu bar, notifications, deep links, file drag-and-drop, auto-update).

**Architecture:** Tauri 2 (Rust core + system webview, stable single-webview-per-window API). One `WebviewWindow` per connected server with its own data directory; switching servers raises the target window. Rust core owns accounts, keychain (Stronghold), tray, shortcuts, deep-link routing, notifier, updater. Small Vite/TS frontend provides only the native shell pages (login, settings, quick-capture).

**Tech Stack:** Tauri 2.x, Rust (stable), `tauri-plugin-stronghold`, `tauri-plugin-deep-link`, `tauri-plugin-single-instance`, `tauri-plugin-global-shortcut`, `tauri-plugin-notification`, `tauri-plugin-updater`, Vite + TypeScript (vanilla; no React framework needed for the tiny shell UI), GitHub Actions matrix (macos-latest, windows-latest, ubuntu-latest).

**Spec:** [../specs/2026-05-20-desktop-app-design.md](../specs/2026-05-20-desktop-app-design.md)

```rust
use crate::error::{AppError, AppResult};
use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};
use std::path::{Path, PathBuf};
use uuid::Uuid;

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct Account {
    pub id: Uuid,
    pub label: String,
    pub server_url: String,
    pub username: String,
    pub last_active: DateTime<Utc>,
}

#[derive(Debug, Clone, Serialize, Deserialize, Default)]
pub struct Settings {
    #[serde(default = "default_shortcut")]
    pub shortcut_quick_capture: String,
    #[serde(default)]
    pub launch_at_login: bool,
    #[serde(default = "default_channel")]
    pub auto_update_channel: String,
}

fn default_shortcut() -> String { "CmdOrCtrl+Shift+N".into() }
fn default_channel() -> String { "stable".into() }

#[derive(Debug, Clone, Serialize, Deserialize, Default)]
pub struct AccountsFile {
    pub accounts: Vec<Account>,
    pub default_active: Option<Uuid>,
    #[serde(default)]
    pub settings: Settings,
}

pub fn load(path: &Path) -> AppResult<AccountsFile> {
    if !path.exists() {
        return Ok(AccountsFile::default());
    }
    let s = std::fs::read_to_string(path)?;
    Ok(serde_json::from_str(&s)?)
}

pub fn save(path: &Path, file: &AccountsFile) -> AppResult<()> {
    if let Some(parent) = path.parent() {
        std::fs::create_dir_all(parent)?;
    }
    let tmp = path.with_extension("json.tmp");
    let json = serde_json::to_string_pretty(file)?;
    std::fs::write(&tmp, json)?;
    std::fs::rename(&tmp, path)?;
    Ok(())
}

pub fn add(file: &mut AccountsFile, label: String, server_url: String, username: String) -> Account {
    let acct = Account {
        id: Uuid::new_v4(),
        label,
        server_url,
        username,
        last_active: Utc::now(),
    };
    file.accounts.push(acct.clone());
    if file.default_active.is_none() {
        file.default_active = Some(acct.id);
    }
    acct
}

pub fn remove(file: &mut AccountsFile, id: Uuid) -> AppResult<Account> {
    let idx = file.accounts.iter().position(|a| a.id == id)
        .ok_or_else(|| AppError::AccountNotFound(id.to_string()))?;
    let acct = file.accounts.remove(idx);
    if file.default_active == Some(id) {
        file.default_active = file.accounts.first().map(|a| a.id);
    }
    Ok(acct)
}

pub fn touch(file: &mut AccountsFile, id: Uuid) {
    if let Some(a) = file.accounts.iter_mut().find(|a| a.id == id) {
        a.last_active = Utc::now();
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use tempfile::tempdir;

    #[test]
    fn round_trip_persistence() {
        let dir = tempdir().unwrap();
        let p: PathBuf = dir.path().join("accounts.json");
        let mut f = AccountsFile::default();
        add(&mut f, "Home".into(), "https://k.example".into(), "pascal".into());
        save(&p, &f).unwrap();
        let f2 = load(&p).unwrap();
        assert_eq!(f.accounts, f2.accounts);
        assert_eq!(f.default_active, f2.default_active);
    }

    #[test]
    fn add_sets_default_only_when_empty() {
        let mut f = AccountsFile::default();
        let a = add(&mut f, "A".into(), "https://a".into(), "u".into());
        assert_eq!(f.default_active, Some(a.id));
        let b = add(&mut f, "B".into(), "https://b".into(), "u".into());
        // Still A
        assert_eq!(f.default_active, Some(a.id));
        let _ = b;
```

```rust
use crate::error::{AppError, AppResult};
use reqwest::Client;
use serde::{Deserialize, Serialize};

const LOGIN_PATH: &str = "/api/auth/login";

#[derive(Debug, Serialize)]
struct LoginBody<'a> { username: &'a str, password: &'a str }

#[derive(Debug, Deserialize)]
pub struct LoginResponse {
    pub user_id: Option<String>,
    pub username: Option<String>,
}

pub struct AuthClient { http: Client }

impl AuthClient {
    pub fn new() -> AppResult<Self> {
        let http = Client::builder().cookie_store(true).build()?;
        Ok(Self { http })
    }

    pub async fn login(&self, server_url: &str, username: &str, password: &str)
        -> AppResult<LoginResponse>
    {
        let url = format!("{}{}", server_url.trim_end_matches('/'), LOGIN_PATH);
        let resp = self.http.post(&url)
            .json(&LoginBody { username, password })
            .send().await?;
        if !resp.status().is_success() {
            return Err(AppError::AuthFailed(resp.status().as_u16()));
        }
        Ok(resp.json::<LoginResponse>().await.unwrap_or(LoginResponse {
            user_id: None, username: Some(username.into())
        }))
    }
}
```

```rust
pub mod keychain {
    use crate::error::{AppError, AppResult};
    use std::path::PathBuf;
    use std::sync::Mutex;
    use tauri::{AppHandle, Manager, Runtime};
    use uuid::Uuid;

    // Stronghold snapshot path: <app_config_dir>/secrets.stronghold
    // Snapshot password: derived from a per-install random value stored at
    // <app_config_dir>/stronghold.key (created on first use). This is NOT a
    // user secret; it's an at-rest encryption key that itself relies on
    // filesystem permissions. For higher security, replace with OS keychain.
    fn snapshot_path<R: Runtime>(app: &AppHandle<R>) -> AppResult<PathBuf> {
        let dir = app.path().app_config_dir()
            .map_err(|e| AppError::Keychain(e.to_string()))?;
        std::fs::create_dir_all(&dir)?;
        Ok(dir.join("secrets.stronghold"))
    }

    fn snapshot_key<R: Runtime>(app: &AppHandle<R>) -> AppResult<Vec<u8>> {
        let dir = app.path().app_config_dir()
            .map_err(|e| AppError::Keychain(e.to_string()))?;
        let key_path = dir.join("stronghold.key");
        if !key_path.exists() {
            use rand::RngCore;
            let mut k = [0u8; 32];
            rand::thread_rng().fill_bytes(&mut k);
            std::fs::write(&key_path, k)?;
            // Best-effort restrict to user-read on Unix.
            #[cfg(unix)]
            {
                use std::os::unix::fs::PermissionsExt;
                let _ = std::fs::set_permissions(&key_path, std::fs::Permissions::from_mode(0o600));
            }
        }
        Ok(std::fs::read(&key_path)?)
    }

    static LOCK: Mutex<()> = Mutex::new(());

    pub fn store<R: Runtime>(app: &AppHandle<R>, id: &Uuid, password: &str) -> AppResult<()> {
        let _g = LOCK.lock().unwrap();
        let path = snapshot_path(app)?;
        let key = snapshot_key(app)?;
        let stronghold = iota_stronghold::Stronghold::default();
        let snap_password = key.clone();
        let client_path = b"kryton".to_vec();
        let client = stronghold.create_client(&client_path)
            .map_err(|e| AppError::Keychain(e.to_string()))?;
        let store = client.store();
        store.insert(id.as_bytes().to_vec(), password.as_bytes().to_vec(), None)
            .map_err(|e| AppError::Keychain(e.to_string()))?;
        if path.exists() {
            stronghold.load_client(&client_path)
                .map_err(|e| AppError::Keychain(e.to_string()))?;
        }
        stronghold.commit_with_keyprovider(
            &iota_stronghold::SnapshotPath::from_path(&path),
            &iota_stronghold::KeyProvider::try_from(snap_password)
                .map_err(|e| AppError::Keychain(e.to_string()))?,
        ).map_err(|e| AppError::Keychain(e.to_string()))?;
        Ok(())
    }

    pub fn read<R: Runtime>(app: &AppHandle<R>, id: &Uuid) -> AppResult<String> {
        let _g = LOCK.lock().unwrap();
        let path = snapshot_path(app)?;
        let key = snapshot_key(app)?;
        let stronghold = iota_stronghold::Stronghold::default();
        let client_path = b"kryton".to_vec();
        stronghold.load_client_from_snapshot(
            &client_path,
            &iota_stronghold::KeyProvider::try_from(key)
                .map_err(|e| AppError::Keychain(e.to_string()))?,
            &iota_stronghold::SnapshotPath::from_path(&path),
        ).map_err(|e| AppError::Keychain(e.to_string()))?;
        let client = stronghold.get_client(&client_path)
            .map_err(|e| AppError::Keychain(e.to_string()))?;
        let store = client.store();
        let v = store.get(id.as_bytes())
            .map_err(|e| AppError::Keychain(e.to_string()))?
            .ok_or_else(|| AppError::Keychain("no password for account".into()))?;
        String::from_utf8(v).map_err(|e| AppError::Keychain(e.to_string()))
    }

    pub fn delete<R: Runtime>(app: &AppHandle<R>, id: &Uuid) -> AppResult<()> {
        let _g = LOCK.lock().unwrap();
        let path = snapshot_path(app)?;
        let key = snapshot_key(app)?;
        let stronghold = iota_stronghold::Stronghold::default();
        let client_path = b"kryton".to_vec();
        stronghold.load_client_from_snapshot(
            &client_path,
            &iota_stronghold::KeyProvider::try_from(key.clone())
                .map_err(|e| AppError::Keychain(e.to_string()))?,
            &iota_stronghold::SnapshotPath::from_path(&path),
        ).map_err(|e| AppError::Keychain(e.to_string()))?;
        let client = stronghold.get_client(&client_path)
            .map_err(|e| AppError::Keychain(e.to_string()))?;
        let store = client.store();
        store.delete(id.as_bytes())
            .map_err(|e| AppError::Keychain(e.to_string()))?;
        stronghold.commit_with_keyprovider(
            &iota_stronghold::SnapshotPath::from_path(&path),
            &iota_stronghold::KeyProvider::try_from(key)
                .map_err(|e| AppError::Keychain(e.to_string()))?,
        ).map_err(|e| AppError::Keychain(e.to_string()))?;
        Ok(())
    }
}
```

```rust
    // page navigation. open_or_focus opens the server URL which (if not yet
    // logged in) will show Kryton's own login page in the webview.
    window_mgr::open_or_focus(&app, &acct)?;
    // Close the shell login window if it exists.
    if let Some(w) = app.get_webview_window("login") {
        let _ = w.close();
    }
    Ok(())
}

#[tauri::command]
pub async fn switch_to<R: Runtime>(
    app: AppHandle<R>,
    state: State<'_, AppState>,
    account_id: Uuid,
) -> AppResult<()> {
    let acct = {
        let mut f = state.accounts.lock().unwrap();
        crate::accounts::touch(&mut f, account_id);
        f.accounts.iter().find(|a| a.id == account_id).cloned()
            .ok_or_else(|| AppError::AccountNotFound(account_id.to_string()))?
    };
    state.save()?;
    window_mgr::open_or_focus(&app, &acct)?;
    window_mgr::hide_all_except(&app, &account_id);
    Ok(())
}

#[tauri::command]
pub async fn close_server<R: Runtime>(
    app: AppHandle<R>,
    account_id: Uuid,
) -> AppResult<()> {
    window_mgr::close(&app, &account_id)
}
```

**Files:** Create `src-tauri/src/deep_link.rs`.

- [ ] **Step 1: Write parsing + routing with tests**

Create `src-tauri/src/deep_link.rs`:

```rust
use crate::accounts::AccountsFile;
use crate::ipc::AppState;
use crate::window_mgr;
use tauri::{AppHandle, Manager, Runtime};
use url::Url;
use uuid::Uuid;

#[derive(Debug, PartialEq, Eq)]
pub struct Parsed {
    pub host: String,
    pub path: String,
}

pub fn parse(input: &str) -> Option<Parsed> {
    let u = Url::parse(input).ok()?;
    if u.scheme() != "kryton" { return None; }
    let host = u.host_str()?.to_string();
    let path = if u.path().is_empty() { "/".to_string() } else { u.path().to_string() };
    Some(Parsed { host, path })
}

pub fn find_account_id(file: &AccountsFile, host: &str) -> Option<Uuid> {
    file.accounts.iter().find_map(|a| {
        let server = Url::parse(&a.server_url).ok()?;
        if server.host_str() == Some(host) { Some(a.id) } else { None }
    })
}

pub fn handle_argv<R: Runtime>(app: &AppHandle<R>, argv: &[String]) {
    for arg in argv {
        if let Some(parsed) = parse(arg) {
            handle(app, parsed);
            return;
        }
    }
}

pub fn handle<R: Runtime>(app: &AppHandle<R>, parsed: Parsed) {
    let st: tauri::State<'_, AppState> = app.state();
    let acct_id = {
        let f = st.accounts.lock().unwrap();
        find_account_id(&f, &parsed.host)
    };
    let h = app.clone();
    tauri::async_runtime::spawn(async move {
        let st: tauri::State<'_, AppState> = h.state();
        if let Some(id) = acct_id {
            let _ = crate::ipc::switch_to(h.clone(), st, id).await;
            if let Some(w) = h.get_webview_window(&window_mgr::label_for(&id)) {
                let target_url = {
                    let f = h.state::<AppState>();
                    let f = f.accounts.lock().unwrap();
                    let acct = f.accounts.iter().find(|a| a.id == id).cloned();
                    acct.map(|a| format!("{}{}", a.server_url.trim_end_matches('/'), parsed.path))
                };
                if let Some(u) = target_url {
                    let _ = w.eval(&format!("window.location.href = {}", serde_json::to_string(&u).unwrap()));
                }
            }
        } else {
            // Unknown host — emit event the shell-ui can show as a modal.
            let _ = h.emit("deep-link:unknown", &parsed.host);
            let _ = crate::open_add_server_window(&h);
        }
    });
}

#[cfg(test)]
mod tests {
    use super::*;
    use crate::accounts::{add, AccountsFile};

    #[test]
    fn parses_kryton_url() {
        let p = parse("kryton://k.example.com/notes/foo.md").unwrap();
        assert_eq!(p.host, "k.example.com");
        assert_eq!(p.path, "/notes/foo.md");
    }

    #[test]
    fn rejects_other_schemes() {
        assert!(parse("https://k.example.com/").is_none());
    }

    #[test]
    fn matches_account_by_host() {
        let mut f = AccountsFile::default();
        let a = add(&mut f, "A".into(), "https://k.example.com:8080".into(), "u".into());
        assert_eq!(find_account_id(&f, "k.example.com"), Some(a.id));
        assert_eq!(find_account_id(&f, "other.example"), None);
    }
}
```

```rust
use tauri::{AppHandle, Runtime};
use tauri_plugin_updater::UpdaterExt;

pub async fn check_and_prompt<R: Runtime>(app: AppHandle<R>) {
    let updater = match app.updater() { Ok(u) => u, Err(e) => { tracing::warn!("updater: {e}"); return; } };
    match updater.check().await {
        Ok(Some(update)) => {
            tracing::info!("update available: {}", update.version);
            // Emit to the shell-ui or settings window to prompt the user.
            let _ = app.emit("update:available", &update.version);
        }
        Ok(None) => tracing::info!("no update"),
        Err(e) => tracing::warn!("update check failed: {e}"),
    }
}

#[tauri::command]
pub async fn apply_update<R: Runtime>(app: AppHandle<R>) -> Result<(), String> {
    let updater = app.updater().map_err(|e| e.to_string())?;
    if let Some(update) = updater.check().await.map_err(|e| e.to_string())? {
        let mut downloaded = 0;
        update.download_and_install(
            |chunk, _total| { downloaded += chunk; },
            || { tracing::info!("downloaded {downloaded} bytes"); },
        ).await.map_err(|e| e.to_string())?;
        app.restart();
    }
    Ok(())
}
```

Register `apply_update`. In `.setup`, after deep-link setup:

```rust
        tokio::time::sleep(std::time::Duration::from_secs(24 * 60 * 60)).await;
        updater::check_and_prompt(h.clone()).await;
    }
});
```
